### Итоговая подготовка временного ряда

Для дальнейшего анализа оставляем дневной ряд `sales_clean`.

- Дневной ряд сначала строится на полном календаре через `resample('D').sum()`, поэтому дни без продаж получают значение `0`.
- В итоговом датасете оставляем нули только по субботам и в период `2010-12-25`...`2011-01-03`, потому что эти провалы календарно объяснимы выходными и праздничным периодом.
- Все остальные нулевые значения удаляются из `sales_clean`, так как они выглядят как нерегулярные пропуски продаж и могут мешать дальнейшему анализу.
- Аномалии также удаляются из итогового ряда, потому что они могут искажать оценки тренда, сезонности и параметров модели.

Параметры поиска аномалий: скользящее окно `14` предыдущих дней, текущая точка исключается из окна через `shift(1)`, границы рассчитываются как `Q1 - 3 * IQR` и `Q3 + 3 * IQR`, где `IQR = Q3 - Q1`. Нули по субботам и в период `2010-12-25`...`2011-01-03` не участвуют в расчете IQR и не считаются аномалиями. Использую большой IQR, чтобы как можно меньше данных удалить. Визуально аномалий не так много обнаружено, но не хочется их удалять на глаз, поэтому использую IQR

### Интерпретация графиков

- На графике средних продаж по месяцам основные пики приходятся на май, ноябрь и декабрь. Для товара `WHITE HANGING HEART T-LIGHT HOLDER` это выглядит логично: это декоративный подсвечник для дома и подарков, поэтому высокий спрос в ноябре-декабре можно связать с предновогодними покупками, подарками и сезонным декором.
- Майский пик выглядит как отдельный локальный всплеск спроса: товар не является строго новогодним, он подходит для домашнего декора в течение года, поэтому часть продаж может приходиться на весенний сезон.
- На графике средних продаж по дням недели заметен недельный календарный эффект: субботы дают минимальное значение, а основные продажи приходятся на рабочие дни.
- На амплитудном спектре главный пик находится около частоты `1/7`, то есть соответствует периоду примерно 7 дней. Это подтверждает выраженную недельную сезонность.
- Амплитуда показывает силу колебания: чем выше пик на спектре, тем сильнее соответствующая периодичность влияет на продажи.
- Скалограмма CWT показывает, когда именно проявлялись разные периоды колебаний. Яркие области около горизонтальной линии 7 дней означают интервалы, где недельная сезонность была особенно заметна.

# ДЕКОМПОЗИЦИЯ

### Выводы по декомпозиции

- Для этого ряда выбран `MSTL`, потому что он позволяет одновременно выделить несколько сезонных компонент: недельную (`7` дней) и приближенную месячную (`30` дней). Это лучше соответствует предыдущему анализу: недельность видна на спектре и CWT, а различия по месяцам заметны на графике средних продаж.
- Трендовая компонента показывает общий уровень продаж без регулярных недельных и месячных колебаний. Сила тренда около `0.305`, то есть долгосрочная динамика есть, но она не доминирует над сезонными колебаниями.
- Недельная сезонная компонента выражена сильнее всего: ее сила около `0.494`. Это подтверждает устойчивый недельный календарный паттерн продаж.
- Месячная сезонная компонента слабее недельной, но тоже заметна: ее сила около `0.265`. Для декоративного подсвечника это логично, потому что спрос может усиливаться в отдельные месяцы, особенно ближе к подарочным и сезонным периодам.
- Вывод: в ряду есть выраженная недельная сезонность и дополнительная месячная компонента. Поэтому `MSTL` здесь информативнее, чем обычный `STL` с одним периодом.

# СТАЦИОНАРНОСТЬ

### Выводы по стационарности

- Для проверки использованы два теста с разными нулевыми гипотезами: `ADF` проверяет наличие единичного корня, а `KPSS` проверяет стационарность вокруг постоянного уровня.
- Для исходного ряда `ADF` дает `p-value < 0.05`, поэтому гипотеза о единичном корне отвергается: ряд можно считать стационарным.
- Для исходного ряда `KPSS` дает `p-value >= 0.05`, поэтому гипотеза о стационарности не отвергается. Это согласуется с результатом `ADF`.
- Преобразование ряда не требуется: оба теста указывают, что исходный очищенный ряд уже стационарен.
- ACF показывает автокорреляцию по лагам: заметные пики около лагов `7`, `14`, `21` дней дополнительно подтверждают недельную структуру ряда.
- Визуально скользящее среднее и скользящее стандартное отклонение колеблются, но не показывают сильного устойчивого ухода, который противоречил бы результатам тестов.
